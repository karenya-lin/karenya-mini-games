# 借一扇窗 — 灰盒原型規格

狀態：Grok 待認領。先做可玩的獨立灰盒，以一扇窗與有限探索呈現空間感。探索內容和最終視覺仍待定；本文件不代表已有實作或已通知外部 AI。

## 範圍

- 使用 React、TypeScript、React Three Fiber；程式与依賴放在本目錄，不先建立跨案共用框架、物理引擎、後端或付費 SDK。
- 一扇窗與三層可辨識的景深：近景、中景、遠景。可用簡單幾何與色塊灰盒，但受限視角下仍能看出層次與視差。
- 場景採 30 秒循環。owner 記錄每層循環變化及起點；實測完整周期與至少兩次循環接縫，不能有明顯跳切、逐輪漂移或重复建立物件。
- 滑鼠控制受限視角探索；不得變成自由移動或走出窗外。owner 記錄視角／位移上限、輸入映射與回中策略。touch 提供等價的受限拖曳探索，區分探索手勢與互動點啟動。
- 提供少量、位置固定、可找到的探索點及明確回饋。owner 灰盒前在工作單記錄數量、位置、啟動條件與回饋／重複啟動策略。探索點位置不得隨機移動；有限視角內每個點都實際可達。
- 操作不依賴 hover：探索點可用明確的 click／tap 啟動，提示與控制在 touch 上也可發現；不能要求滑入後才能出現必需按鈕或訊息。
- reset 可隨時使用：回復視角、30 秒計時／場景起點、探索點與回饋狀態，并取消未完成手勢。reset 後仍可操作並重複探索。

## 待定決策

窗的灰盒尺寸、三層距離與內容、循環曲線、視角上限、探索點数量及具體回饋待 owner 提案並記錄。不帶入私人小說場景、Studio／Bot 素材或外部付費資產。最終 UIUX／美術另審。

| 案例 | 通過條件與交付證據 |
| --- | --- |
| 技術與獨立性 | React／TypeScript／R3F 的獨立專案，可依記錄指令安裝、run、build、test；沒有共用框架或後端前置要求。 |
| 一窗三層 | 截圖与操作紀錄可辨識唯一窗框及近／中／遠三層；視角變化顯示層次。 |
| 30 秒循環 | 記錄計時方法、完整周期与至少兩個接縫的實測；reset 後周期由起點開始且不疊加計時。 |
| 受限視角 | 桌面與 touch 到達各極限後仍留在設定範圍；多次拖曳與重新觸碰不累積漂移。 |
| 固定探索點 | 列出所有探索點位置與從 reset 出發的啟動步驟；每點皆可達且 click／tap 有可见回饋。 |
