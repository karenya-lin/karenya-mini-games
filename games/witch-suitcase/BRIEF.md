# 魔女的行李箱 — 灰盒原型規格

狀態：Grok 待認領。先做可驗證玩法的灰盒；角色性格、物品外觀、詳細互動規則與結局敘事都是候選待定。本文件不代表已有實作或已通知外部 AI。

## 範圍

- 單一平面行李箱與恰好六件有個性的物品。以簡單幾何、暫用名稱／文字回饋表現性格；owner 先在工作單列出六件物品及候選性格，待確認後採用，不引入私人角色或素材。
- 提供平面拖曳、旋轉與吸附。旋轉須有桌面與 touch 都可用的明確控制；owner 記錄角度粒度、吸附目標／距離及觸發時機。
- 物品旋轉後的實際碰撞形狀須參與重疊與越界檢查。可採矩形／凸多邊形與旋轉座標／SAT 等簡單方法；僅用未旋轉外框或中心點不足以驗收。不導入物理引擎。
- 放置時顯示合法／不合法與原因；非法位置不得進入有效配置。owner 明載採回復上個合法位置或拒絕放置等一致策略。旋轉、吸附後也必須重新驗證；邊界接觸與物品接觸的容差須明載。
- 恰好三條可見、可理解的互動規則：可在規則面板查看，操作後可見觸發／解除回饋。詳細條件尚未決定，owner 須列出每條觸發条件、涉及物品、優先順序及觀察方式。
- 恰好兩個可達結局，提供明確達成回饋。owner 須定義各結局條件、衝突時的選擇方式，以及從初始狀態達成各結局的合法配置與操作步驟；不能只有理論條件而無可達證據。
- reset 可隨時使用，恢復六件物品的初始位置、角度、規則狀態、結局及拖曳／選取狀態；可重複遊玩。

## 待定決策

物品名稱／性格、形狀／尺寸、行李箱尺寸、旋轉步距、吸附設定、三條規則及兩個結局敘事與条件均尚未定案。owner 灰盒前在工作單記錄候選方案與兩個可達配置；不要把候選設計寫成使用者已確認的角色設定。

## 驗收案例

| 案例 | 通過條件與交付證據 |
| --- | --- |
| 六件物品 | 六件均可辨識、操作，性格有簡單可見回饋；沒有多餘或遺失物品。 |
| 拖曳／旋轉／吸附 | 桌面與 touch 可完成全操作；每次旋轉與吸附後幾何仍有效。 |
| 重疊 | 分別測試未旋轉與旋轉後重疊、不重疊及邊緣接觸；判定依實際旋轉形狀與已記錄容差。 |
| 越界 | 測試四邊、角落及中心仍在箱內但旋轉角越界的情況；非法配置被阻止並有原因。 |
| 三條規則 | 每條都有明示條件，提供觸發、解除及衝突處理的重現步驟和畫面。 |
| 兩個結局 | 提供兩套從 reset 出發的合法操作步驟、最終配置及結局截圖；兩個都實際達成。 |
| 重複／reset | 重複拖曳、旋轉、吸附、取消／放開與至少三輪 reset；操作中及結局後 reset 不留下殘影、鎖住的輸入或舊規則狀態。 |
