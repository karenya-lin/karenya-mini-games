# 魔女的行李箱 — 灰盒原型

Owner：Grok（愛麗咧）。工作單 #1。設定皆為**候選**，未經使用者確認。

## 執行

無依賴、無建置步驟（原生 HTML／Canvas／ES module）。

```bash
cd games/witch-suitcase
python3 -m http.server 5181   # 或 npm start（npx http-server）
# 開 http://localhost:5181/
npm test                      # = node --test test/game.test.js（Node 20）
# 瀏覽器煙測（另裝 playwright＋chromium，伺服器開著）：OUT=shots node test/smoke.browser.mjs
```

## 操作

- 拖曳（滑鼠或手指）移動物品；左側為行李箱 600×400，右側為桌面暫放區。
- 點選物品後按 ⟲／⟳（或鍵盤 R、Shift+R）旋轉 45°。Esc／pointercancel 取消拖曳。
- 「重來 reset」隨時可按，含拖曳中與結局後。

## 候選設定

| 物品 | 尺寸 | 性格 |
| --- | --- | --- |
| 掃帚 | 300×40 | 愛逞強 |
| 黑貓抱枕 | 100×100 | 怕寂寞 |
| 魔藥瓶 | 60×100 | 易碎神經質 |
| 咒語書 | 140×100 | 愛整齊 |
| 水晶球 | 90×90 | 會安撫人 |
| 月亮斗篷 | 200×120 | 懶洋洋 |

- 幾何：旋轉後矩形四頂點＋SAT（`src/geometry.js`），不用外框、不用物理引擎。
- 容差：物品間穿透 ≤0.5 視為接觸（合法）；越界容許 0.5。
- 旋轉：45° 步距。吸附：放開時中心吸到 5 格線，旋轉後外框離箱壁 ≤15 時貼齊。旋轉與吸附後一律重新驗證。
- 非法策略：一律退回上一個合法位置／角度，訊息列顯示原因（重疊對象／超出哪邊／跨在箱子與桌面之間）。物品須完全在箱內或完全在桌面上。

### 三條規則（規則面板即時顯示 ● 觸發／○ 未觸發）

1. **易碎**：魔藥瓶與掃帚都在箱內且間距 <20 → 危險。
2. **安撫**：黑貓抱枕與水晶球都在箱內且間距 <20 → 黑貓安靜。
3. **整齊**：咒語書在箱內且角度不是 0°／180° → 書頁亂翻。

### 兩個結局（六件都在箱內才判定）

- **行李箱暴走**：① 成立。與順利出發衝突時此結局優先。
- **順利出發**：② 成立且 ①③ 皆不成立。

可達配置（中心座標，角度皆 0°，從 reset 依序拖入：掃帚→斗篷→書→藥瓶→黑貓→水晶球）：
