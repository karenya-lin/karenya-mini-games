# 魔女的行李箱 — 原型

Owner：Grok（愛麗咧）。工作單 #1。物品、客人、規則皆為**候選**設定。

## 執行

無依賴、無建置（原生 HTML／Canvas／ES module，Node 20 跑測試）。

```bash
cd games/witch-suitcase
python3 -m http.server 5181          # 開 http://localhost:5181/（?chapter=N 指定章節，?preview 為入口頁自動示範）
npm test                             # node --test：game.test.js＋meta.test.js
# 瀏覽器煙測（另裝 playwright＋chromium，伺服器開著）
OUT=shots node test/smoke.browser.mjs   # 六章全過、影子、爆炸、reset
OUT=shots node test/meta.browser.mjs    # 星等、差一點三星、圖鑑、每日挑戰、存檔
```

## 玩法

- 拖曳（滑鼠或手指）移動；拖曳中顯示**影子**：綠色＝可以放（附格子座標，如 J2），紅色＝不行（附原因）。
- 點選後 ⟲／⟳（或 R、Shift+R）旋轉 45°。放開時吸附並檢查；非法一律退回上一個合法位置並說明原因。
- 箱子有 20 單位的**格線**，上方欄 A、B、C…，左側列 1、2、3…；被物品實際（旋轉後）形狀壓到的格子會上色。
- 游標：一般／滑到物品＝張開的手，拖曳中＝握拳（`assets/cursor-open.png`、`cursor-grab.png`，缺檔自動用系統 grab／grabbing）。

- 💖 必要（good）：要成立才能過關。💢 不可以（bad）：成立就不能過關。💥 會爆炸（boom）：一成立立刻爆炸（閃光、碎片、震動、音效），1.8 秒後**整關重來**。
- 結局：**順利出發**（全部在箱內、💖 都成立、💢 都不成立）／**行李箱暴走**（任何 💥）。
- 每章的可達解（座標）在 `src/game.js` 的 `CHAPTERS[].configs`，單元測試會從 reset 逐一實際放置驗證。

## 上癮機制

- **星等**：步數（成功放置＋旋轉）與時間。三星＝步數 ≤ 物品數＋1 且 時間 ≤ 物品數×12 秒；二星＝步數 ≤ 物品數×2 且 時間 ≤ 物品數×30 秒。
- **差一點三星**：只差 ≤2 步且 ≤10 秒時提示「差一點就三星！只差 N 步／秒」＋「再挑戰三星」按鈕。
- **連擊**：連續把物品放進箱子（沒有非法嘗試）就累加；×2 起有加分、浮字、粒子、輕微震動，音高隨連擊上升（WebAudio 合成音效，無音檔）。
- **圖鑑**：過關後收錄該章物品（36 件），未收錄顯示「？？？」。
- **每日挑戰**：以日期為種子，固定章節＋兩塊 2×2 格「污漬」障礙（保證避開該章標準解，一定可解）；每日最佳星數另存。
- **存檔**：`localStorage` 的 `witch-suitcase.save.v1`（解鎖進度、各章最佳星、圖鑑、每日、總分）；壞檔會自動重設。過關後鎖住操作，按「再玩一次／下一位客人」繼續。

## 美術

正式美術為點陣 PNG，放 `assets/`（完整 36 件物品清單、足跡與建議像素見 `assets/README.md`）。缺檔時：原始六件、箱子、背景用程式內 SVG 暫用圖；其他物品畫色塊＋名稱。物品圖拉伸到碰撞矩形繪製，所以畫面＝碰撞形狀。
